# SpyEye

**SpyEye** is a port scanner and exploit search tool designed for network security auditing and educational purposes. It helps users identify open ports on target systems and find potential vulnerabilities by searching for known exploits.

## 📋 Requirements
- Python 3.8+
- `searchsploit`: This tool is part of the Exploit Database package and needs to be installed separately.
  - On Debian/Ubuntu based systems (including WSL Kali), install with: `sudo apt update && sudo apt install exploitdb`
  - For Windows users, `searchsploit` requires WSL (Windows Subsystem for Linux) with a distribution like Kali Linux.
- Internet connection

## 🎮 Quick Start Guide

1. **Launch SpyEye**
   - Execute the main script: `python SpyEye-Demo.py` (or double-click if your system is configured to run Python scripts).
